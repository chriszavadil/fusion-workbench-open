# Research and application update - 9 September 2026

## What this version changes
The new Research library makes the full cleared research reports, experiment notes, selected numerical summaries and app updates readable within the native Unreal app and browser companion. Search covers full text, titles, dates, topics and status. Each record carries its original scope and content hash. Older conclusions are retained, with superseded status where identified, instead of being mistaken for today's accepted design.

The collection is broader than the old eight-topic dashboard. It includes materials/release work, periodic fuel ledgers, central-solenoid fatigue, cooling and distribution comparisons, confinement studies, machine-specific control/observer references, software corrections and this update. Some raw archives and third-party datasets remain unavailable, private or not fully integrated. A catalogued artifact is not necessarily an independently validated experiment. This is not a claim that every old test now has an interactive replay.

## Scientific work completed alongside the interface
Before computing, we checked the existing PROCESS documentation, source and issue history. The confinement-normalization correction is already discussed in issue 652, with related scaling limits in issue 3534. We applied that known accounting principle to the exact two candidate records rather than presenting it as a discovery. A thermal/deposited-power comparison gives 1.086393 for r838 and 0.937743 for r900; these are model diagnostics, not measured global H98 values. The separate report explains the double-counted radiation term and independent arithmetic checks.

No new reactor optimization or physical experiment is claimed. Neither geometry, its approved input, its stored electrical output nor its physical-validation status has changed. Future experimental comparisons must match energy, absorbed/source-power, radiation, transient and geometry conventions before either factor can be treated as support for a reactor.

## How to read the library
Use Research library, type a word or date, then choose a record. The selected-configuration filter includes only records explicitly assigned to that configuration; it does not reassign external machine benchmarks to our reactor. Read the highlighted scope/status before the body. Full text is displayed as selectable source text; equations and tables retain their original written form. Reading does not execute code or alter an approved reference.

No private email, raw correspondence, home directory, device identifier or credential is included. Referenced publications are linked, not copied into the application without rights. Records with unresolved data access retain a public-safe description only.

## Release status
This is a local development update based on the cleaned 0.2.1 release. The earlier public repository remains withdrawn; its old history must not be reopened. Publication of the updated app and current clean source requires a fresh public repository supplied by the project owner. That publishing dependency does not block local research or application work. There is no unattended research team or public live-compute service.
