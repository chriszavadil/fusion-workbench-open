# MAST sample request scope

The external request is limited to current public access documentation or a small redistribution-safe numeric sample. It does not ask for restricted shot data, proprietary control code, credentials, or endorsement of any result.

Requested minimum schema: shot ID, monotonic time in seconds, plasma current in amperes, magnetic-axis R/Z in metres or documented equivalents, at least one active PF-current channel, explicit signal units and coordinate conventions, processing/source provenance, quality flags, and redistribution/publication terms. Train/calibration/holdout groups will be frozen before holdout scoring.
