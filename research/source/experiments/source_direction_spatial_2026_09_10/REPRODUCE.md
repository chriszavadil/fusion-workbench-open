# Reproduce the source-direction test and 3D data projection

This directory contains the declared four-case experiment, safe result/track projections and fixed-input hashes. It is not a complete reactor model. Read the Source direction and 3D transport report in the Research library before using its results.

## Replay the data projection
With a compatible Python and NumPy, run `python analyze_and_export.py` from this directory. It reads the four `runs/*/RESULT.json`, `TRACKS.json` and `GEOMETRY.json` files, validates their hashes and scores, computes the stated source-law contrasts, and writes `KEY_RESULTS.json` and `transport_lab.json`. This is arithmetic replay of recorded calculations, not a fresh Monte Carlo run.

The generated `transport_lab.json` is copied to `app/data` for the browser and `native/Content/WorkbenchData` for Unreal. Both copies must be byte-identical. The app uses cm coordinates with a Y-axis reflection in Unreal, recorded time in seconds and source-normalized voxel scores. Rendering never substitutes a new physics calculation.

## Repeat transport in a fresh directory
Use the prior study's isolated OpenMC 0.15.2 environment and recorded nuclear-data files. Copy the model, materials, input and admission files, and a private `local_cross_sections_path.txt` pointing to a verified OpenMC cross-section XML. Do not copy completed `runs` directories when creating a new execution experiment. The DATA_MANIFEST hashes identify the nuclear-data files; the files themselves and absolute local paths are not bundled.

Use `run_spatial_gate_recovery.py`, whose singular `settings.track` spelling matches the installed 0.15.2 API. The original `run_spatial_gate.py` is retained as execution history, not recommended for a new run. The recovery driver retains an existing statepoint rather than repeating it when only track postprocessing is missing. Do not reuse the experiment identifier for changed source, material or geometry inputs. Each complete tally run is bounded to 600 seconds; a track-only companion is bounded to 120 seconds.

All original HDF5 statepoints, track files and private execution logs remain in the local evidence archive. They are not published as application source. The first case's single-batch track companion is documented separately; its histories are not double-counted as additional tally evidence. No parameter was optimized after examining the outcomes.

## Rebuild visualization assets
`native/create_transport_materials.py` creates the original three materials through Unreal editor scripting. Runtime hardware and trajectories are generated by `FusionTransportLab.cpp`, not by a hand-painted image or opaque external renderer. The packaged runtime needs no editor or Python to inspect the recorded dataset. The source tests verify coordinate mapping, data identity, field normalization, predeclared track selection and the study's limitations.

Building or viewing a result is not a validation of the physical materials, source, temperature, flow distribution, pressure-vessel design or whole-reactor breeding performance.
